# 🧠 Exam Forge

Exam Forge is a premium, full-stack quiz platform designed for serious learners. It provides a production-grade experience with real-time features, comprehensive analytics, and a modern, high-performance UI.

![Exam Forge Logo](/public/logo.png)

## 🚀 Key Features

### 🌐 Full-Stack & Real-Time
- **Real-Time Global Chat**: Built with Socket.io, allowing students to discuss questions and share knowledge instantly across the platform.
- **Bi-directional Communication**: Live connection status indicators (Online/Offline) and message history persistence.

### 📚 Extensive Subject Library
- **20+ Specialized Subjects**: Including JavaScript, Python, MySQL, React, Figma, C++, TypeScript, C, PHP, Swift, Kotlin, and more.
- **Dynamic Content**: Each subject contains at least 10 high-quality questions with instant feedback.
- **Vector Icons**: Official Devicon SVG logos for every programming language and tool.

### 🎭 Engagement & Education
- **Programmer Humor Widget**: An automated educational joke rotation system that updates every 60 seconds, featuring over 100+ developer-focused jokes.
- **Custom Optical UI**: A unique **Magnifying Glass Lens** custom cursor that uses real-time brightness and contrast filters for a premium interactive feel.

### 📊 Dashboard & Analytics
- **Performance Tracking**: Detailed stats on total quizzes taken, average scores, best categories, and historical attempts.
- **Leaderboards**: Compete with other learners and track your global ranking.
- **Timed Exams**: Realistic exam conditions with countdown timers and automatic submission.

### 🛡️ integrity & Security
- **Anti-Cheat System**: Tab-switch detection with automated warnings to ensure exam integrity.
- **Account Management**: Secure authentication system with role-based access for Admins and Users.

## 🛠️ Technology Stack

- **Frontend**: React 18, Vite, TypeScript
- **Backend**: Node.js, Express, Socket.io
- **Styling**: Tailwind CSS, Framer Motion (Animations), Lucide React (Icons)
- **State Management**: React Query, Context API
- **Tooling**: Concurrently (Full-stack process management)

## 🏁 Getting Started

To run the full-stack application locally:

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Run the Application**:
   This command starts both the Vite frontend and the Socket.io backend server simultaneously.
   ```bash
   npm run dev
   ```

3. **Access the App**:
   - Frontend: `http://localhost:8080`
   - Backend: `http://localhost:3001`
